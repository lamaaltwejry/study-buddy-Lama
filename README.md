# Simple Daily Task Manager

A simple and easy-to-use Python project to manage daily tasks. I built this to help organize daily to-dos and keep track of things efficiently.

## Features
- View all current tasks.
- Add new tasks easily.
- Remove or complete tasks when finished.

## How to Run
1. Make sure you have Python installed on your computer.
2. Download or clone this repository.
3. Run the script using the terminal:
   ```bash
   python task_manager.py
   ```
